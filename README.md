# Portfólio - Renan Evangelista

Site pessoal feito como trabalho da faculdade (Análise e Desenvolvimento de Sistemas), com apresentação, habilidades, projetos, currículo editável e links de contato. Responsivo para celular e computador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3 (via CDN)

## Uso de inteligência artificial

Este projeto foi feito com o apoio de inteligência artificial, com base nos códigos que eu já havia desenvolvido (versões anteriores do site e atividades da faculdade). A IA ajudou a organizar, corrigir e melhorar o material, e eu tenho um certo domínio sobre o que foi mostrado.

## Como executar

Baixe os arquivos e abra o `index.html` no navegador.
